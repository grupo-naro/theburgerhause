# Tarjeta "Primer día" (imprimir y dejar al lado de la PC)

## Al llegar

1. Prendé la PC y la **impresora** (papel puesto, tapa cerrada).
2. Abrí el navegador en la dirección del sistema. **Ingresar** con tu usuario y contraseña.
3. Elegí **tu estación** (Mostrador 1..4 o Delivery 1..5). Es la de tu PC.
4. Arriba a la derecha tiene que decir **"Impresora lista"** (verde) y **"En vivo"**. Tocá **Activar sonido**.
5. Si dice **"Sin agente"** más de 6 minutos: avisá a soporte (teléfono abajo).

## Lo que más vas a usar

| Soy... | Hago esto |
| --- | --- |
| **Cajera, venta en mostrador** | **Venta** → tocar productos → pago → **llamador** → **Cobrar e imprimir** |
| **Cajera, pedido web de retiro** | **Retiro en local** → **Aprobar** (o **Aprobar y pagado** tildando que verificaste la transferencia) → **Listo** → **Llamar / Para retirar** → **Entregado** |
| **Encargada, pedido web de delivery** | **Gestión Delivery** → **Por aprobar** → **Aprobar** → **Listo** → tildar pedidos → **Asignar a <cadete>** → **Entregado** |
| **Encargada, cadete vuelve** | **Rendición** → nombre del cadete → contar → **Confirmar rendición** → **Sí, confirmar** |

## Reglas de oro

- **Transferencia: primero mirá que la plata llegó**, después tildá y aprobá. Si no llegó: **Rechazar → Pago no acreditado**.
- **No sale comanda de cocina impresa.** **DEFINIR POR EL DUEÑO:** cómo se entera la cocina de cada pedido (pantalla, papel, aviso de voz u otro): todavía no hay una decisión tomada. Papel: Delivery sale con **dos** tickets (delivery + cliente);
  Mostrador con **uno** (cliente).
- **Cuadro rojo "impresión falló"** → revisá papel y cable → **Reimprimir**. No reimprimas "por las dudas": sale otro papel.
- **Los pedidos web de delivery solo aparecen en Delivery; los de retiro, en Mostrador.** Es normal no ver el del otro sector.
- **Cerrá sesión** al irte (**Cerrar sesión**, arriba a la derecha).

## Durante el período de prueba (operación en paralelo)

Cada pedido se carga **en el sistema nuevo y también en el sistema anterior** (pxw). El sistema anterior sigue siendo el que vale hasta que
el dueño diga lo contrario. Anotá en la planilla de diferencias cualquier cosa rara (`docs/guias/operacion-en-paralelo.md`).

## Si se cae todo (internet, sistema o impresora)

1. **No pares de vender.** Tomá los pedidos **a mano** en el block: número, hora, productos y aclaraciones, dirección y teléfono (delivery), forma de pago, total.
2. Pasá el papel a cocina como siempre.
3. Avisá a soporte. Cuando vuelva el sistema, **no reimprimas** lo que ya entregaste. Plan completo: `docs/guias/plan-contingencia.md`.
